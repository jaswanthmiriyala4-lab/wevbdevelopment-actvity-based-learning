🍽️ Golden Spoon Restaurant & Cafe Website
A modern, responsive restaurant and café website built with HTML5 and CSS3. The website showcases menu items, chef profiles, restaurant ambience, customer testimonials, opening hours, location details, and an online table reservation form.

✨ Features
Responsive Navigation Menu
Elegant Hero Section
Restaurant Menu Categories
Chef Profiles
Ambience Showcase
Customer Testimonials
Opening Hours Section
Location & Contact Information
Table Reservation Form
Mobile-Friendly Design
Modern Typography using Google Fonts
